# Immersive Intelligence Coordinate Calculator

A simple coordinate calculator for Immersive Intelligence's Ballistic Computer and Artillery Howitzer.

## Build Requirements
Any C++ Compiler that can compile C++23.
If building with Visual Studio 2022, or Visual Studio 2026, right click on the C++ project go to -> `Properties` -> `Configuration Properties` -> `C++ Language Standard -> Preiview - ISO C++23` / `ISO C++23 Standard` (select `ISO C++23 Standard` if C++23 has been fully released.)

## How To Build
CTRL+SHIFT+B (or whatever your build keybind is)
Press the hollow green triangle next to `Local Windows Debugger`
